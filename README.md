Music and Soundeffects organization tool.
Lists and Sorts Music in a given folderstructure and allows the user to tag and search specific pieces. This Tool is meant to help me have an overview over my library of soundeffects for game development and ambiance music. Over the years, gathering clips from different sources led to an disorganized mess that is a pain to searhc through if only I need a specific sound.

Everything an artist needs, put neatly in his basket to sort through.
